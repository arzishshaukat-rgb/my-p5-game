A 2D arcade-style game built using **p5.js** as part of the Hack Club Ghostship workshop. 

## About the Game
In this game, the player controls a moving paddle at the bottom of the screen to catch falling red objects while avoiding dangerous bombs. Every successful catch increases your score.
